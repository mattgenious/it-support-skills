MIT licensed; no support service, remote access server or guaranteed repair.

## Authorized generic support migration (0.3.0)

This release adapts our original generic support guidance under the user's
explicit authorization for public release. Source material was privately held and unlicensed for
public reuse by others; this is an owner-authorized adaptation, not ingestion of
third-party skills. The public library's MIT license covers the resulting generic
material, not the private originals. No outside text, customer data, internal
infrastructure, product CLI, schema or collection/transport integration is copied.

| Original source skill | Generic public disposition | Product-specific disposition |
| --- | --- | --- |
| windows-machine-triage | evidence-led-triage; OS routers; investigate-windows-application-device-failure | Collection/remote-access adapter stays private |
| windows-performance-optimization | identify-windows-resource-bottleneck; diagnose-windows-startup-contention; storage/security routes | No product dependency in generic judgment |
| windows-reliability-investigation | investigate-unexpected-restart; investigate-windows-application-device-failure | Snapshot adapter stays private |
| windows-safe-repair | verify-reversible-repair; recover-uncertain-operation | Remote return path and reporting integration stay private |
| windows-security-posture | assess-windows-security-posture | Product collection and retired internal baseline details stay private |
| windows-storage-health | assess-windows-storage-health | Managed diagnostic/acquisition adapter stays private |
| macos-performance-optimization | Existing app-stall owner strengthened; diagnose-macos-memory-pressure; diagnose-macos-storage-pressure; diagnose-macos-background-contention | No product dependency in generic judgment |
| linux-performance-optimization | Existing bottleneck owner strengthened; diagnose-linux-boot-service-delay; diagnose-linux-network-performance | No product dependency in generic judgment |
| collect-support-bundle | collect-support-evidence (scope, provenance, integrity, warnings, redaction, transfer and cleanup) | Product collector, schema and transfer commands stay private |
| Agent mistake-reporting (private source) | Stabilize/report/confirm material unintended mutations in verify-reversible-repair | Named product ledger, authenticated CLI and retry integration stay private |

The private source inventory is recorded here for migration traceability only;
these previous names are not additional installable public skills. Product-specific
adapters are independently owned and not distributed in this plugin. No generic
judgment from the ten originals is intentionally left awaiting extraction. This
is guidance coverage, not a claim that every OS repair is implemented: device
investigation is not a complete peripheral repair service, storage assessment is
not data recovery, and security posture is not compromise eradication.

Task source links identify maintained platform references used by the originals
or native interfaces named in the adaptation. They were not fetched or independently
revalidated during this migration. Verify installed tool/platform support before
use; a citation is not evidence that a machine fix has succeeded.

## Agent harnesses

- **Copilot CLI:** `/plugin marketplace add mattgenious/it-support-skills`, then
  `/plugin install it-support@it-support-skills`.
- **Claude Code:** `/plugin marketplace add mattgenious/it-support-skills`, then
  `/plugin install it-support@it-support-skills`.
- **Codex:** marketplace metadata is in `.agents/plugins/marketplace.json` and the
  plugin descriptor in `.codex-plugin/plugin.json`. Use your client's supported
  marketplace interface; CLI/version support varies. No remote install claimed.
- **OpenCode:** from a checkout, run `pwsh -File scripts/install-opencode.ps1`.
  Use `-Destination` to select a different skill directory. Existing skills are
  never overwritten; `-WhatIf` previews the operation.
- **Other skill-aware agents:** use `plugins/it-support/skills` as the source.

Only install with the user's authority. Skills guide agents; they do not grant
machine access or approve effects. These manifests are locally validated;
marketplace acceptance and UI loading vary by harness/version and are not
certification by those vendors.

## Contributions

Add original, source-backed guidance to the correct capability owner. Include
trigger, decisive observations, authority boundaries, recovery and verification.
Distinguish observed failures from explanations and known fixes from hypotheses.
Add no credentials, customer records or private infrastructure. For third-party
material, establish license/provenance before incorporating it.

Regenerate with `python scripts/package_skills.py`, then validate discovery and
packaging with `python scripts/validate.py`. Validation derives task counts from
canonical placement, checks one router per OS, all local reference targets,
README discovery, exact generated output and aligned plugin versions. Reads use
explicit UTF-8 on Windows; generated output uses LF consistently. Preview OpenCode
installation with `pwsh -File scripts/install-opencode.ps1 -WhatIf` before an
owner-authorized install. No machine diagnostics run during packaging checks.

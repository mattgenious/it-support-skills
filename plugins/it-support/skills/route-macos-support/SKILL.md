# Route a macOS support task to its focused capability.

Select a task from its observed symptom, not a generic area label.
- Application stall: [performance/diagnose-application-stall](../diagnose-macos-application-stall/SKILL.md).
- Sleep/wake continuity: [sleep-wake/verify-sleep-wake-continuity](../verify-macos-sleep-wake-continuity/SKILL.md).
- Memory pressure/swap growth: [performance/diagnose-memory-pressure](../diagnose-macos-memory-pressure/SKILL.md).
- Low APFS space or storage contention: [storage/diagnose-storage-pressure](../diagnose-macos-storage-pressure/SKILL.md).
- Login/maintenance/energy contention: [performance/diagnose-background-contention](../diagnose-macos-background-contention/SKILL.md).
- Unclear symptom: [evidence-led-triage](../evidence-led-triage/SKILL.md).
- Uncertain prior operation: [recover-uncertain-operation](../recover-uncertain-operation/SKILL.md).
- Proposed repair: [verify-reversible-repair](../verify-reversible-repair/SKILL.md).

- Evidence for another technician: [collect-support-evidence](../collect-support-evidence/SKILL.md).

Load only the relevant owner. Area directories are organization, not executable
skills. No capability listed here grants permission to change a machine.

# Macos Performance Triage

Relate the complaint to an exact application or system workload. Read bounded
CPU/memory pressure, storage availability, process behavior and relevant recent
crash information using maintained native tools. Distinguish Spotlight indexing,
thermal constraints, memory pressure and an application stall using evidence.

A frozen remote display is not proof of system sleep. Use actual sleep/wake events
and state observations for lifecycle claims. Preserve system motion, privacy,
login, power and security preferences; do not change them to make tests pass.
Prefer application-scoped reversible remedies and validate on the original
workload. VM evidence does not qualify a physical or different-architecture Mac.

# Route a Linux support task to its focused capability.

Select a task from its observed symptom, not a generic area label.
- Workload bottleneck: [performance/identify-resource-bottleneck](../identify-linux-resource-bottleneck/SKILL.md).
- Slow boot/service readiness: [boot/diagnose-boot-service-delay](../diagnose-linux-boot-service-delay/SKILL.md).
- Slow network workload: [network/diagnose-network-performance](../diagnose-linux-network-performance/SKILL.md).
- DNS/proxy/TLS or connectivity failure: [network path](../diagnose-network-path/SKILL.md).
- Recover files or test a backup: [backup restore](../verify-backup-restore/SKILL.md).
- Stuck CUPS print job: [print job](../diagnose-cups-print-job/SKILL.md).
- Kernel panic/oops/lockup or vmcore: [kernel crash](../investigate-linux-kernel-crash/SKILL.md).
- Unclear symptom: [evidence-led-triage](../evidence-led-triage/SKILL.md).
- Uncertain prior operation: [recover-uncertain-operation](../recover-uncertain-operation/SKILL.md).
- Proposed repair: [verify-reversible-repair](../verify-reversible-repair/SKILL.md).

- Evidence for another technician: [collect-support-evidence](../collect-support-evidence/SKILL.md).

Load only the relevant owner. Area directories are organization, not executable
skills. No capability listed here grants permission to change a machine.

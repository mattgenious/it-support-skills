# Linux support

For an unclear symptom start with [triage](../evidence-led-triage/SKILL.md).
Choose [resource bottleneck](../identify-linux-resource-bottleneck/SKILL.md),
[boot/service delay](../diagnose-linux-boot-service-delay/SKILL.md),
[network performance](../diagnose-linux-network-performance/SKILL.md), or
[kernel crash](../investigate-linux-kernel-crash/SKILL.md).

Shared outcomes: [network path](../diagnose-network-path/SKILL.md),
[CUPS printing](../diagnose-cups-print-job/SKILL.md),
[backup restore](../verify-backup-restore/SKILL.md),
[evidence handoff](../collect-support-evidence/SKILL.md).
Use [reversible repair](../verify-reversible-repair/SKILL.md) for changes;
routing grants no machine-change authority.

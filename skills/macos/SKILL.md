# Route a macOS support task to its focused capability.

Select a task from its observed symptom, not a generic area label.
- Application stall: [performance/diagnose-application-stall](./performance/diagnose-application-stall/SKILL.md).
- Sleep/wake continuity: [sleep-wake/verify-sleep-wake-continuity](./sleep-wake/verify-sleep-wake-continuity/SKILL.md).
- Memory pressure/swap growth: [performance/diagnose-memory-pressure](./performance/diagnose-memory-pressure/SKILL.md).
- Low APFS space or storage contention: [storage/diagnose-storage-pressure](./storage/diagnose-storage-pressure/SKILL.md).
- Login/maintenance/energy contention: [performance/diagnose-background-contention](./performance/diagnose-background-contention/SKILL.md).
- DNS/proxy/TLS or connectivity failure: [network path](../shared/diagnose-network-path/SKILL.md).
- Recover files or test a backup: [backup restore](../shared/verify-backup-restore/SKILL.md).
- Stuck CUPS print job: [print job](../shared/diagnose-cups-print-job/SKILL.md).
- App privacy/access denial: [app permission](./access/diagnose-app-permission/SKILL.md).
- USB/Bluetooth/audio/dock disconnect: [peripheral disconnect](./devices/diagnose-peripheral-disconnect/SKILL.md).
- Unexpected restart or panic report: [kernel panic](./reliability/investigate-kernel-panic/SKILL.md).
- Duplicate-file candidates: [duplicate review](./storage/review-duplicate-files/SKILL.md).
- Unclear symptom: [evidence-led-triage](../shared/evidence-led-triage/SKILL.md).
- Uncertain prior operation: [recover-uncertain-operation](../shared/recover-uncertain-operation/SKILL.md).
- Proposed repair: [verify-reversible-repair](../shared/verify-reversible-repair/SKILL.md).

- Evidence for another technician: [collect-support-evidence](../shared/collect-support-evidence/SKILL.md).

Load only the relevant owner. Area directories are organization, not executable
skills. No capability listed here grants permission to change a machine.

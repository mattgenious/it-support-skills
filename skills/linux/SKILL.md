# Linux support

For an unclear symptom start with [triage](../shared/evidence-led-triage/SKILL.md).
Choose [resource bottleneck](performance/identify-resource-bottleneck/SKILL.md),
[boot/service delay](boot/diagnose-boot-service-delay/SKILL.md),
[network performance](network/diagnose-network-performance/SKILL.md), or
[kernel crash](reliability/investigate-kernel-crash/SKILL.md).

Shared outcomes: [network path](../shared/diagnose-network-path/SKILL.md),
[CUPS printing](../shared/diagnose-cups-print-job/SKILL.md),
[backup restore](../shared/verify-backup-restore/SKILL.md),
[evidence handoff](../shared/collect-support-evidence/SKILL.md).
Use [reversible repair](../shared/verify-reversible-repair/SKILL.md) for changes;
routing grants no machine-change authority.
